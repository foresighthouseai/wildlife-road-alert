# Credits for the files in this folder

Every image here was produced by this project's own code. The underlying
photos and data belong to their creators, credited below. Nothing in this
folder is drawn from the Pond5 dashcam clip (item 141272328, commercial
licence); that clip is not redistributed.

## Dataset evaluation (Roboflow deer photos)

- `eval_chart.png`, `eval_examples.png`, `eval_summary.json`
  Data: Deers on roads (Scalersai, Roboflow Universe), CC BY 4.0 —
  https://universe.roboflow.com/scalersai/deers-on-roads
  Boxes in the examples grid were drawn by SAM 3.1 (this project) against
  the dataset's human boxes. Images are 416×416 and stretched; scores may
  be lower than on full-resolution video.

## Clip results table

- `results.png`
  Generated by this project (`python app.py --batch test_videos/`) from its
  own run summaries. It is a text table only and contains no video frames
  and no third-party imagery.
